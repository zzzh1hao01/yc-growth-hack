# HouseholdIQ — 3-Minute Demo Flow

Shoot against: **[householdiq-insurance.vercel.app](https://householdiq-insurance.vercel.app/)**  
Branch: `feature/insurance-app`

Full spoken script: **[DEMO_SCRIPT.md](./DEMO_SCRIPT.md)**

---

## Before you record

- Browser 100% zoom, bookmarks bar hidden
- Complete **agent** onboarding if prompted
- Pick a **green** sprite with **!** badge
- Run `scripts/import-insurance-leads.sh` if map is empty

---

## Step 1 — Problem hook (0:00–0:45)

**Say:** insurance agents, broad lists, no signal on coverage gaps, manual dataset hunting.

**Show:** spreadsheet b-roll or blank screen.

---

## Step 2 — Reveal the board (0:45–1:15)

1. Open the app
2. **Say:** *"HouseholdIQ — a bounty board for scored SF properties."*
3. Point out: **Coverage Board** header
4. Point out legend — green / yellow / red, **!** = stronger signal

---

## Step 3 — Click a property (1:15–2:15)

1. Click green + ! sprite
2. Walk panel: address → priority score → risk signals → coverage gap → home age → AI context
3. Optional chat: *"Why was this property flagged?"*

**Do not** mention contractors, door knocking, Yelp, Angi, or behavioral homeowner profiles.

---

## Step 4 — Data, AI, backend (2:15–2:45)

**Say:** SF Open Data, assessor + permits, Python scoring, Convex real-time, OpenAI summaries.

---

## Step 5 — Close (2:45–3:00)

Wide map pan.

**Say:** from broad searching → data-driven property discovery.
