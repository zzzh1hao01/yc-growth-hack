Build the HouseholdIQ **insurance** outbound pipeline in THIS spreadsheet. HouseholdIQ is a San Francisco insurance lead app. Agents click "Pursue lead" on the coverage board; rows queue in our backend and auto-push via webhook.

IMPORTANT — Orange Slice built-ins only:
- Use **Import from webhook** for auto-push on Pursue (primary).
- Import from API is fallback only if webhook is unavailable.
- Use enrichment columns for contact waterfall + LinkedIn.
- Use Gmail integration column for touch 1 / touch 2.
- Use HTTP POST column (or webhook action) to sync status back to HouseholdIQ.

Replace YOUR_OUTREACH_WEBHOOK_SECRET with the value from Convex dashboard → Settings → Environment Variables → OUTREACH_WEBHOOK_SECRET.

HouseholdIQ API (insurance deployment):
- Base: https://compassionate-ptarmigan-622.convex.site
- Header: Authorization: Bearer YOUR_OUTREACH_WEBHOOK_SECRET
- Content-Type: application/json (POST only)

Endpoints:
- GET  /orangeslice/import?limit=25  → { ok, count, data: [ flat rows ] }
- POST /orangeslice/status            → body { household_id, status, event?, detail? }

Valid status values: sheet_synced, touch1_ready, touch1_sent, touch2_sent, replied, meeting, won, lost, d2d_planned

STEP 4 — Enrichment column: "Find contact"

For rows where email AND phone are both empty AND owner_first_name is not empty AND owner_last_name is not empty:

Run contact enrichment / contact waterfall with:
- firstName = owner_first_name
- lastName = owner_last_name
- location = city + ", " + state
- company = address
- required = email and phone
- prefer personal contacts over work

Write first valid personal email to email column.
Write first valid personal phone to phone column.
Append "contact_waterfall" to activity_log.

After enrichment succeeds, HTTP POST to https://compassionate-ptarmigan-622.convex.site/orangeslice/status with:
{
  "household_id": "<household_id>",
  "status": "touch1_ready",
  "event": "contact_found",
  "email": "<email if found>",
  "phone": "<phone if found>"
}
Header: Authorization: Bearer YOUR_OUTREACH_WEBHOOK_SECRET

This syncs contact info back to HouseholdIQ, which posts a Slack alert if the agency saved an incoming webhook in Settings.
